---
name: python-bugfix
description: 以测试证据驱动的 Python 缺陷修复流程
---
先查看项目结构，定位源码和测试目录。
读取相关测试与实现，不要仅凭文件名猜测。
在修改前运行 python_unittest，记录明确的失败证据；如果测试无法加载，先区分测试环境问题与业务逻辑问题。
优先修复源码，不得为了让测试变绿而削弱、删除或篡改测试，除非用户明确要求修复测试本身。
采用最小修改：单行错误优先使用 replace_line，其他情况使用精确文本补丁。
工具拒绝参数时，根据错误重新读取目标文件并纠正参数，不得绕过校验。
修改后运行同一测试集。只有测试通过后才能返回 final；final 应说明失败原因、实际修改和验证结果。
