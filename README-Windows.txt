DeepSeek Web Agent - Windows 客户端
===================================

快速开始
--------
1. 请先完整解压 DeepSeekWebAgent-windows.zip，不要直接在压缩包内运行。
2. 双击 DeepSeekWebAgent.exe。
3. 在“项目目录”中选择 Agent 可以查看和修改的文件夹。
4. 在“给 Agent 的指令”中用自然语言描述任务。
5. 点击“开始会话并发送”。首次使用会打开专用浏览器，请登录 DeepSeek。
6. Agent 请求写文件或运行程序时，客户端会显示确认窗口；确认内容后再批准。
7. 第一项任务结束后，可以继续输入补充要求并点击“发送下一项任务”。

示例指令
--------
先查看项目目录和必要文件，然后新建 hello.py，实现打印 Hello World；完成后运行并验证结果。

使用提醒
--------
- Agent 只能在你选择的项目目录内读写文件。
- “自动批准只读操作”只会自动允许查看目录、读取文件等操作，不会自动批准写入。
- 不确定某项操作是否安全时，请在确认窗口选择拒绝，再给 Agent 补充说明。
- 登录信息和浏览器资料保存在：%LOCALAPPDATA%\DeepSeekWebAgent
- Windows 可能提示这是未签名应用。当前测试包没有购买代码签名证书，请只运行来自可信来源的副本。
- 运行需要可正常访问 DeepSeek 网页，并安装 Chrome 或 Edge。

结束使用
--------
点击“结束会话”会关闭当前 Agent 会话；再次启动后可开启新会话。
